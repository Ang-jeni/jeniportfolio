# Angelin Jenita Arul — Production Portfolio

Static GitHub Pages portfolio built with semantic HTML, CSS and vanilla JavaScript.

## Features
- Light / System / Dark theme with localStorage persistence
- System theme via prefers-color-scheme
- Responsive navigation
- Project and skill filters
- Accessible native project dialogs
- Scroll progress and reveal animations
- Reduced-motion support
- Responsive layouts from 320px upward
- No backend or authentication required

## Resume

## GitHub Pages
Keep `index.html` in the repository root and deploy from the desired branch/root folder through GitHub Pages settings.
